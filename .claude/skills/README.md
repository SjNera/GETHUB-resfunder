# Vendored design skills

These six skills are copied unchanged from [emilkowalski/skills](https://github.com/emilkowalski/skills)
at commit `4061b67b8d976a186aca118594f54b638c5f718a` (MIT License, © 2026 Emil Kowalski — see `LICENSE`
in each folder). Claude Code loads them automatically for anyone working in this repo.

| Skill | Why it's here |
|---|---|
| `emil-design-eng` | Motion and polish rules behind the design tokens in `web/src/app/globals.css` |
| `apple-design` | Materials (the floating nav and glass cards), type, press feedback, wayfinding |
| `pick-ui-library` | The library picks: Base UI, Sonner, NumberFlow, dnd kit, zustand, clsx, cva |
| `break-ui` | Stress-test screens with worst-case data |
| `mobile-native` | Respondents answer on phones: dvh, safe areas, 16px inputs, tap targets |
| `review-animations` | Review any new motion before merging |

To update, re-copy from a newer commit and change the hash above.
