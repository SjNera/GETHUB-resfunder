# ResFunder demo site

`index.html` is the single-file demo of the whole product: the landing page, the final sign-in (email → Who are you? → About you → Where you are with consent → What describes you best → wallet → You're all set; no 6-digit code), the researcher dashboard with the redesigned review drawer, the respondent's answer flow, and results for closed surveys (summary, per-question answers, individual responses).

Open it in a browser. It needs no build or server. Sign-in, MetaMask and transactions are simulated, and accounts are saved in the browser. Amounts are in testnet BNB (tBNB).
