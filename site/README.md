# ResFunder demo site

`index.html` is the single-file demo of the whole product: the landing page, sign-up and sign-in (school email, Who are you?, setup steps, MetaMask wallet, no 6-digit code), the researcher dashboard with the redesigned review drawer, and the respondent's answer flow.

Open it in a browser. It needs no build or server. Sign-in, MetaMask and transactions are simulated, and accounts are saved in the browser. Amounts are in testnet BNB (tBNB).
